Step 1 Load your list

In Google Sheets choose File → Download → Comma-separated values (.csv), then pick that file here. Columns A, B and C are used: name, street, city/state/ZIP.

Fine-tune position (only if your test page is off)

Use negative numbers to move left or up. These numbers are remembered in this browser for next year.

Printing so they line up

  1. Open the PDF in Preview or Adobe Reader.
  2. In the print window set Scale to 100% (or "Actual size"). Turn off "Fit to page" or "Scale to fit". This is the most common reason labels drift.
  3. Paper size: US Letter.
  4. Print the test page on plain paper first. Hold it behind a label sheet against a window and check that the boxes match.
  5. Load the label sheets the way your printer feeds them, then print the labels PDF.
